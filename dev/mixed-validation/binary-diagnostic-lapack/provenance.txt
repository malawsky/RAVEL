Norm-pivoted LAPACK QR-basis null calibration; one independently generated dataset per replicate.
500 samples of N = 1500 unrelated trios; seeds 620001 through 620500; binary threshold = 0.6.
Genetic covariance: spouse 0.2, child-parent 0.6. GWAS errors: spouse 0, child-parent 0.5; noise variances 0.6 and 1.3.
Binary latent outcome = 0.4 Gc + 0.1 Gm + 0.05 Gf + independent N(0,1).
Both genotypes and outcomes were independently regenerated in every replicate; no fixed-genotype repeated outcomes.
The selected 500 seeds match the discarded default-QR experiment so numerical behavior can be compared on identical regenerated data.
